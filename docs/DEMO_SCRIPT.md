# 候选人正式演示录制脚本（建议150秒）

正式视频由候选人亲自录制；内部开发录制不作为提交视频。最终文件必须60–180秒。

| 时间 | 操作 | 讲解要点 |
|---|---|---|
| 0–10秒 | 展示产品、进入连接设置 | 研究机器人精细操作。密钥在服务端，仅输入研究访问码；密码框保持遮挡。 |
| 10–30秒 | 产业链图谱、下游应用依据 | 驱动/力觉服务末端，3D视觉可直接服务系统。连线是功能依赖，不是供货关系。 |
| 30–45秒 | 奥比关系卡片与原文 | E4是3D产品收入，机器人应用仍未单列金额；集团财务不能替代业务收入。 |
| 45–65秒 | 跨市场比较矩阵 | 展示型号、主动DOF/关节或精度测试条件。可比功能与不可比财务口径同时展示。 |
| 65–85秒 | 事件与传导、真实订单案例 | 外部/需求观察到部件、公司业务、交付和财务。展示成立条件与反证，量增不保证利增。 |
| 85–125秒 | 持续更新的柯力半年报案例 | 点击检索与PDF哈希核验，载入片段，真实Kimi提取。新销量证据仍E3，核对后确认写入云端。网络较慢时适当剪掉等待段。 |
| 125–145秒 | 同步云端、柯力当前版本问答 | 问“销量增长是否代表集团利润增长”，引用新记录及集团财务；原文、期间与限制可追溯。 |
| 145–155秒 | 验收与交付、源码与测试 | URL可操作，GitHub/README/AI与验证记录齐备；解释研报接口和企业治理边界。 |

录制前：准备访问码；核对官方PDF第9页（业务）和第5页（集团财务）。如果相同材料已经确认，重复确认会去重，直接演示历史与问答即可，不需要删除审计历史。所有情景计算输入均为用户假设，未经独立性能测试的产品参数不得排名。

避免录到Kimi/扶摇/iFinD API密钥、GitHub token或签名密钥。访问码不上传公开仓库。录制后检查时长、声音、画面和真实点击，再与Web URL、仓库一并提交。
